# Generic anatomy only, no patient data

Version 1 builds its coronary tree model from published normal-anatomy coordinate data, not from patient CT scans or real angiograms. A CT-based tree would look more realistic, but it would need segmentation work and would bring patient-privacy rules into a tool that fellows share by link. Patient images must therefore never be committed to this project; any future patient-specific tree needs its own decision on de-identification first.
